## About

Don't trust your opening moves? No problem. **lucky-open** picks one for you — so you can skip the prep and get straight to the game.

## Usage

```bash
# Clone this repo
git clone https://github.com/theprince404/lucky-open.git
```
```bash
# Enter the directory
cd lucky-open
```
```bash
# run the code
python main.py
```
